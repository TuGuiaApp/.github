## Features

- **Búsqueda por categoría**: filtrá profesionales por rubro, calificación y ciudad.
- **Perfiles públicos**: horarios, servicios, fotos y reseñas según el plan.
- **Planes**: Plata (gratis), Oro y Platino con distintos niveles de visibilidad.
- **Reseñas**: los usuarios dejan reseñas post-servicio; el promedio se actualiza automáticamente.
- **WhatsApp**: contacto directo con mensaje predefinido.
- **Recuperación de contraseña**: flujo con código por email, cooldown de 60s.
- **Turnos**: profesionales gestionan su agenda y los usuarios reservan online.
- **Mobile-first**: responsive desde 320px, touch targets ≥ 44px.
